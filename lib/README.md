# Lib Directory

Utility functions, helpers, and shared modules for sunny-stack.

## Overview

Core utilities and helper functions used throughout the application.

## Structure

```
lib/
├── utils/            # Utility functions
├── db/              # Database utilities
├── api/             # API client helpers
└── validation/      # Input validation schemas
```

## Key Components

- **Database utilities**: Prisma client singleton and query helpers
- **API helpers**: Fetch wrappers and error handling
- **Validation**: Zod schemas for input validation
- **Type definitions**: Shared TypeScript types
